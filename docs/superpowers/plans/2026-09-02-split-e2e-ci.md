# Split End-to-End CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Playwright an independent time budget without removing or weakening any existing verification.

**Architecture:** Keep fast and PostgreSQL-backed repository verification in `verify`, move browser installation and Playwright execution into a parallel `e2e` job, and gate containers on both. GitHub Actions remains the authoritative Ubuntu/PostgreSQL service check.

**Tech Stack:** GitHub Actions, Node.js 22.18, pnpm 11.15, PostgreSQL 16, Playwright 1.62.

## Global Constraints

- Every existing CI command remains present.
- GitHub Actions and container images remain commit/digest pinned.
- Checkout credentials are not persisted.
- The E2E timeout is 35 minutes.
- Containers require both `verify` and `e2e`.

### Task 1: Separate browser verification from the main verification job

**Files:**
- Modify: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: root scripts `check`, `test:e2e`, `schemas:check`, `openapi:check`, `conformance`, `audit`, and `scripts/verify-public-packages.mjs`.
- Produces: independent `verify` and `e2e` required jobs; `containers.needs: [verify, e2e]`.

- [ ] **Step 1: Record the current workflow command inventory**

Run:

```bash
rg -n "pnpm (check|test:e2e|schemas:check|openapi:check|conformance|audit)|verify-public-packages|playwright install|needs:" .github/workflows/ci.yml
```

Expected: every command appears once and `containers` currently needs only `verify`.

- [ ] **Step 2: Move Playwright into a dedicated job**

Remove only these steps from `verify`:

```yaml
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm test:e2e
```

Add this sibling job after `verify`:

```yaml
  e2e:
    runs-on: ubuntu-latest
    timeout-minutes: 35
    services:
      postgres:
        image: postgres:16-alpine@sha256:57c72fd2a128e416c7fcc499958864df5301e940bca0a56f58fddf30ffc07777
        env:
          POSTGRES_DB: payops_test
          POSTGRES_PASSWORD: payops
          POSTGRES_USER: payops
        ports:
          - 5432:5432
        options: >-
          --health-cmd "pg_isready -U payops -d payops_test"
          --health-interval 1s
          --health-timeout 3s
          --health-retries 30
    env:
      DATABASE_URL: postgres://payops:payops@127.0.0.1:5432/payops_test
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false
      - uses: pnpm/action-setup@0977fd99725f1db4007ccb2928dbb4e90d06cc86 # v6.0.10
        with:
          version: 11.15.0
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 22.18.0
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm test:e2e
```

Change:

```yaml
  containers:
    needs:
      - verify
      - e2e
```

Also set `persist-credentials: false` on the `verify` checkout to match the security posture of the other jobs.
